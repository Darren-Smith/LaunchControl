# Launch Control

Darren's game launcher + games, packaged for friends' Linux Mint PCs.

- `games/` – sanitised copies of each game (synced from dev folders by `scripts/sync_games.py`)
- `packaging/` – exclude rules, PyInstaller specs, installer
- `scripts/` – sync, asset audit, build/release tools
- `updater/` – Tkinter self-updater
